# Examples

Focused `.yar` programs exercising the language feature by feature.

- `valid/` - idiomatic, well-formed programs. A conforming implementation runs each one successfully.
- `invalid/` - cases a conforming implementation should reject. The rejected construct is marked with a `# ERROR:` comment on the offending line.

`00_grammar_tour.yar` is the runnable twin of the illustrative program in [`../GRAMMAR.md`](../GRAMMAR.md); when the tour changes, keep the two in sync.

Prefer the grammar when an example and the implementation disagree.
