# yarrow-core

Core implementation for the [Yarrow](https://github.com/Yarrow-Programming-Language/yarrow) programming language.

## Overview

`yarrow-core` is the **heart of the Yarrow implementation**. It provides:

- **Tokenization** - Lexical analysis of Yarrow source code
- **Parsing** - Syntax tree construction from tokens
- **Interpretation** - Direct execution without code generation
- **Session management** - Execution session with state management

## Features

### Language Features

- **Stack-based syntax** - Explicit stack manipulation
- **Strong typing** - Type system (types are checked at runtime by the interpreter)
- **Ownership model** - Rust-like ownership with move semantics
- **Borrow checking** - Runtime borrow validation
- **Regions** - Explicit region-based lifetimes
- **Pattern matching** - Powerful pattern matching on types
- **Modules** - Modular code organization with imports/exports
- **Unsafe blocks** - Explicit unsafe boundary for low-level operations

### Execution

The interpreter provides direct execution of Yarrow programs via tree-walking:

| Feature         | Description                              |
| --------------- | ---------------------------------------- |
| **Interpreted** | Direct execution without code generation |

## Usage

As a library:

```rust
use yarrow_core::{Session, SessionOptions};

let opts = SessionOptions::new("my_program.yar");
let session = Session::new(opts);

// Parse and interpret a string
let result = session.interpret_source("main function 1 add print end".to_string());

match result {
    Ok(run_result) => {
        // Execution succeeded
        println!("Result: {:?}", run_result);
    }
    Err(diagnostics) => {
        // Handle parsing/interpretation errors
        eprintln!("Errors: {:?}", diagnostics.batch);
    }
}
```

## Standard Library

The Yarrow standard library (`std`) is embedded in `yarrow-core` and includes:

- `std.io` - Input/output operations
- `std.math` - Mathematical functions
- `std.mem` - Memory allocation and management
- `std.fs` - File system operations

Standard library modules are parsed from source files in `lib/std/`.

## Diagnostics

`yarrow-core` provides a rich diagnostic system with error codes:

| Code | Category        | Description             |
| ---- | --------------- | ----------------------- |
| E1xx | Syntax errors   | Lexical/parse errors    |
| E2xx | Type errors     | Type checking failures  |
| E3xx | Semantic errors | Ownership/region issues |
| E5xx | Runtime errors  | Execution failures      |

Note: Without a type checker, only parsing errors (E1xx) and runtime errors (E5xx) are generated by the interpreter.
